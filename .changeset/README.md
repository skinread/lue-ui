# Changesets

Lue UI versions every `@lue-ui/*` package in lockstep ([ADR-0007](../docs/architecture/adr/0007-package-layout-and-ownership.md)),
so one changeset bumps them all. Add one with `pnpm changeset` for any change a consumer would notice.

Nothing is published yet (user's decision, 2026-10-11): the packages are `"private": true` until publishing starts.
